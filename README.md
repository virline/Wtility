# Wtility

## 概要
Wtilityは、入力されたテキストのUnicode符号点を表示したり、Unicode符号点から文字への変換をリアルタイムに行うユーティリティツールです。HTML、CSS、JavaScriptのみで構成された単一のファイルで動作し、外部との通信を行わないため、セキュアに利用できます。

## 機能

- **Unicode符号点の取得**
  テキストエリアに入力した文字列を1文字ずつ解析し、対応するUnicode符号点（`U+XXXX` 形式）をリアルタイムで表示します。サロゲートペア（絵文字など）も正しく処理されます。

- **符号点からの自動文字変換**
  テキストエリアにUnicodeエスケープシーケンスや符号点の形式を入力すると、自動的に対応する文字に変換されます。

- **変換のオン/オフ切り替え**
  「符号点から自動変換」のトグルスイッチで、自動変換の有効・無効を簡単に切り替えることができます。

## 使い方

1. `index.html` をお使いのウェブブラウザ（Chrome, Edge, Firefox, Safariなど）で開きます。
2. 画面上のテキストエリアに文字を入力すると、下部のエリアに各文字と Unicode 符号点が表示されます。
3. 符号点から文字へ変換したい場合は、テキストエリアに以下の対応形式で入力してください。自動的に文字に置換されます。

### 対応している入力形式

以下の形式で入力すると自動変換が行われます（「符号点から自動変換」がオンになっている場合）。

- `\uXXXX` （例: `\u3042` → `あ`）
- `\u{XXXX}` （例: `\u{1F600}` → `😀`）
- `U+XXXX` または `u+XXXX` （例: `U+3042` → `あ`）

## 動作環境

モダンなウェブブラウザ（ローカル環境で動作します）。
外部ライブラリへの依存はありません。
